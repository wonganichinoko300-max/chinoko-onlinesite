# Chinoko Online

Public-facing educational website for Chinoko Online, built with React and Vite. The learning management system is a separate application and is not included here.

## Run locally

```bash
npm ci
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Site configuration

Update the LMS URL, telephone, WhatsApp number, email, address and social links in `src/config/siteConfig.js`. Replace the LMS placeholder before launch. Programme, subject and learning-resource content lives in `src/data/content.js`.
